# BuzFinanzas_webapp
Web App (PWA) de finanzas personales e inversiones 100% privada y local-first. Cifrado AES-256 en tu dispositivo sin servidores externos. Cartera con cotizaciones online (Yahoo Finance), cálculo real de ganancias, interés compuesto, detector de gastos hormiga y simulador hipoteca vs inversión. Sin suscripciones ni rastreadores.
